# Design and Analysis of Algorithms (DAA) Practicals

This repository contains lab practicals and implementations for the **Design and Analysis of Algorithms (DAA)** course, featuring 12 structured PDF reports (`8762_DAA_01.pdf` through `8762_DAA_12.pdf`).

## 🧠 Key Concepts Covered
- **Divide and Conquer** (e.g., Merge Sort, Quick Sort, Binary Search)
- **Greedy Algorithms** (e.g., Kruskal’s, Prim’s, Knapsack)
- **Dynamic Programming** (e.g., LCS, Matrix Chain Multiplication)
- **Backtracking & Branch and Bound** (e.g., N-Queens, TSP)

## 🛠️ Tools & Languages Used
- **Languages:** C / C++ / Python / Java
- **Documentation:** PDF Lab Reports
